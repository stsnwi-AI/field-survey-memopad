## ユーザーの観察と要求
Ver.1.4.24で図面を指でスライドする動きが以前より使いにくく、選択したオブジェクトを指で移動・編集できなくなった。図面全体の上下左右への指移動は旧方式に近づけて復元し、1回タッチでオブジェクトを選択し、連続2回タッチで編集メニューを出す仕様は維持する。

## 確認した原因
Ver.1.4.23で選択ツール中の指接触を選択済みオブジェクトの上であっても gesture.pan に振り分けたため、元のPDF編集エンジンのoriginalTouchHandlers.down/move/upが呼ばれず、選択済みオブジェクトのドラッグ編集ができなくなった。Ver.1.4.24で1回タップの選択は改善したが、選択されたオブジェクトの移動・サイズ変更ルートは復元されていなかった。

## Ver.1.4.25-devの修正方針と実装
- タッチ開始位置が現在選択済みオブジェクトの上で、選択ツール・編集モードの場合は、オリジナルの編集ポインタ処理を使用する。
- それ以外の通常の指ドラッグは、従来のスクロール／edgeTurnDirectionを使用し、PDFキャンバス上の図面全体を動かす。
- オブジェクトを1回短くタップすると、そのオブジェクトを選択し、次のタッチで編集ドラッグできる状態にする。
- 空白を短くタップすると選択解除し閲覧モードに戻す。
- オブジェクトを移動して指を離したら通常の図面移動モードに戻す。複数選択ON、ペン描画、明示的な図形ツールの操作は既存処理を維持。
- 同じ通常オブジェクトへの2回短いタップで、独立した切り取り・コピー・複製・貼り付けメニューを表示する方式は維持。
- 調査番号ピンの2回タップは写真・メモ表示の専用処理のまま維持。
- 空白ページにも表示する独立「貼り付け」ボタン、PDF埋込の調査記録、写真・メモ・施工指示の保持、斜め端スワイプ、2本指ピンチを変更しない。
- 表示をVer.1.4.25-dev、mobile.jsの読み込みバージョンとService Workerキャッシュを更新。
