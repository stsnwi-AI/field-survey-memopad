## 要望
- PDF図面を広く見たまま編集したい
- 編集ツールを隠すと操作できなくなるため、フローティングパレットを常時表示
- PCでドラッグ、タブレット・スマホで指ドラッグして位置移動
- 既存の編集・調査番号・写真・コメント・施工指示・PDF一体保存を維持
