# 現場調査メモパッド — タブレット上部操作の省スペース化
更新日：2026-11-11
対象：Ver.1.4 開発試験版
開発ブランチ：develop/compact-tablet-header-v1.4-20261111
親ブランチ：develop/draggable-edit-palette-v1.4-20261111

## 要望
タブレットでは「PDFを開く」「別PDFを開く」「編集済みPDFを保存」「パレット表示」など上部操作の高さを抑え、図面を優先して表示する。移動パレットは維持し、編集機能は削除しない。

## 実装
- 1180px以下でヘッダーを横一列、操作ボタンを44pxアイコン中心に統一。
- 540px以下では一部42px幅、44px高さを維持。
- 長いラベルは視覚的に非表示だが、aria-label・titleと元のボタン・イベントは維持。
- 別PDFを開く既存リンクにアイコンとaria-labelを付与。
- ヘッダーのロゴ・アプリ名・バージョン表示をコンパクト化。バージョン表示文字は隠すがDOMには残る。
- PDF一体保存、調査番号、写真、コメント、設定ドロワー、移動パレットは維持。
- offline service workerキャッシュ名を更新。
