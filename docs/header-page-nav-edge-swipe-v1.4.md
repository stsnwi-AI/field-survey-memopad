## 要望・実装
- 固定ページ切り替えが、パレットを上部に配置すると重なる → ページ前後ボタンと番号表示を、最初から上部にある題名と同じヘッダー行に移動。
- 元の固定ページボタンの別行は廃止。元の操作ハンドラーは再利用。
- 倍率切替は既存のドロップダウンを再利用し、PDFワークスペース側に配置。ズーム機能を削除しない。
- 指1本の縦スワイプでページ切り替え：図面の最下端でさらに上方向へ90px以上の明確なスワイプ＝次ページ、最上端でさらに下方向へ90px以上＝前ページ。左右移動や通常の上下スクロールではページを変えない。
- 指2本のピンチ・ペンの書き込み・マウス操作は従来どおり。複数指の動作ではページ切替しない。
- CSSでヘッダー自体をstickyにし、タイトルとページ操作を一体表示。狭い画面はアイコンと文字を縮小。
- モバイルヘルプを更新し、キャッシュを更新。
- 共有の任意機能・パレットの常時ドラッグ・調査番号の切替・削除・写真・メモ・施工指示・PDF一体保存・復元は維持。

## 静的検証
JS構文、既存ナビボタン再利用、上端固定、ズーム維持、ペン描画、指パン・ピンチ、端の判定、閾値、前後ページ、PWAキャッシュ等19項目合格。

## 未検証・既知の注意
- 実機iPad/スマホでのヘッダー幅、端スワイプ、パレットとの重なり、PDF再読込は未検証。
- ページの上端／下端でスワイプ開始した場合のみページが切り替わる。図面途中の縦スワイプは従来どおりスクロール。
- 非常に横幅が小さい画面で題名が縮む可能性あり。レイアウトは実機で再評価。
- タッチペンの認識方式（pointerType=pen）には端末依存性あり。
- ライブラリ、プロジェクト「ファイル（ソース）」への保存は未実施。
