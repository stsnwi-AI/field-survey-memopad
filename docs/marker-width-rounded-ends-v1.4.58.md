- 新規マーカーの標準線幅を8.0から5.0へ。

## 修正実装
- `app.js` に独立した `markerLineWidth` 設定を追加。起動初期値は5.0、0.5〜10.0の0.5刻みで操作できるようにした。
- 保存キー `field-survey-marker-width-v1` を `localStorage` に用い、変更後のマーカー線幅を次の描画、ツール切替、再読み込みでも維持。保存不可の場合は実行中の設定を維持。
- 既存の「色・文字・線の設定」パネル内の線幅▲▼を、**マーカーが選択ツールである間は描画用マーカー幅の操作**に利用。既存オブジェクトを選択した場合は従来どおり選択物の線幅を編集できる。
- `mobile.js` ではマーカー描画モード中も線幅設定欄を表示可能にする。削除確認や写真のデータ経路は変更しない。
- 新規作成するマーカーの `type:'pen',markerStroke:true` に `lineWidth:markerLineWidth` を保存。過去の8.0やその他幅のマーカーには遡及適用しない。
- `paint(c,o)` でマーカー専用に `lineJoin='round'` を指定（既存の `lineCap='round'` は維持）。スタイラスの折れ点を `quadraticCurveTo` で緩やかに接続し、1点の短いマークも丸く描く。通常の手書きペンや旧型四角形マーカーの描画処理は維持。
- この `paint` は編集中キャンバス、縦連続プレビュー、PDF出力で共通利用される。
- `index.html`（上部・右下版）、`workspace.html`を Ver.1.4.58-dev に統一。編集 JS のキャッシュ識別子と `sw.js` のキャッシュ名を更新。
