# 現場調査メモパッド Ver.1.4.41-dev 開発記録
更新日：2026-11-16

## 基準
- 直前の開発版：`develop/stylus-hold-survey-pin-v1.4.40-20261116`
- 今回の開発ブランチ：`develop/standalone-line-width-v1.4.41-20261116`
- Pages公開設定は未変更。

## ユーザー報告
タブレットでオブジェクトを選択すると「書き込みを修正」内のコピー・貼り付け等のボタンが残る。PCでは非表示。線の太さをフォントの下に外出しして「書き込みを修正」の枠自体を非表示にしたい。

## 原因（コード確認）
- `mobile.js`の`updateTouchSelection()`で選択時に`#editor`と`#touchObjectActions`の表示を復活させている。
- 線の太さ`#editLineRow`はその`#editor`内にあり、枠ごと隠すと線幅操作まで消える。
- タブレット向けコピー・貼り付け・複製は`touch-context-menu.js`にも既存操作がある（対象オブジェクトをダブルタッチする）。

## 実装
- `tool-dock.js`：元の`#editLineRow`を新規に複製せず、既存の入力・上下ボタンとイベントハンドラを保持したまま、フォント/太字斜体の設定のすぐ下へ移動。
- `survey-layout.css`：`#editor`と古い`#touchObjectActions`を画面上から非表示。元の処理・DOM・undo・コピー用イベントは削除せず保持。線幅部品は独立したコンパクトな横並びレイアウト。
- `index.html`：ヘッダー・右下とも`Ver.1.4.41-dev`へ更新。CSSとtool-dock.jsのキャッシュキー更新。
- `sw.js`：新キャッシュ名へ変更。
- `app.js`、`mobile.js`、`survey.js`、`touch-context-menu.js`、PDF保存形式は変更なし。

## 未検証・リスク
- PC/タブレット実機で「書き込みを修正」枠が非表示か。
- 線・図形の選択時のみ線幅欄が表示され、線幅を変更できるか。
- タブレットでダブルタッチのコピー・貼り付け・複製・削除・ペン移動を実行できるか。
- ペン長押しの調査写真・コメント表示、PDFの別名保存と再読込。
- 「書き込みを修正」枠の非表示により、別経路で使えると想定した操作に不足がないか、利用者実機で確認する。
