## 2. ユーザー要望
- Ver.1.4.50の上部削除ボタンは赤が濃すぎる。元の淡い赤より少し濃くする程度に調整する。
- アプリ全体のデザインと配色を改めて整理し、現場タブレットでの操作性を向上する。
- 既存機能を維持し、確定した操作仕様を変更しない。

## 3. デザイン監査（ソースの確認）
- 基本`style.css`は旧PDF編集アプリ由来の紫系変数が残るが、`field-theme.css`で現場向け青系へ上書き。
- `survey-layout.css`にはv1.4.48～1.4.50の削除ボタンや選択色の!importantが累積し、同じボタンの色を複数箇所から指定する状態。
- 上部バーの実削除ボタンIDは`surveyPaletteDelete`。別にレガシーな`delete`ボタンがあり、前回まで両方が表示される可能性があった。
- 上部／浮動両配置を使い分け、タッチ対象は少なくとも44pxを維持する必要がある。

## 4. 実装した改善
- 新規`ui-refinement.css`を`survey-layout.css`の後にロードし、歴代CSSは削除・上書きせずUIカラーを最終的に統一。
- 中立操作：白背景・青灰文字・柔らかい青灰の境界線。押下中・選択中のツール：淡い青背景・青枠。
- 調査番号配置ON：淡いオレンジ背景・濃いオレンジ文字・オレンジ枠。OFF：薄いグレー背景・青灰文字。
- 削除：従来の淡赤より少し濃い`#f1d4d9`背景、`#963c49`文字・アイコン、`#d9a0a9`枠。Ver.1.4.50の濃赤`#bd202e`背景を上書きする。
- 実操作は`surveyPaletteDelete`を使用。重複するレガシー`#delete`の表示を`display:none`にするが、DOMとイベント・`originalDelete.click()`による削除確認処理は維持。
- 色・文字・線の設定ボタン、パレット、上部バー、移動パレット、ページ操作、フォーカス表示の背景・枠・影を統一。
- 横一列ツールバーの横スクロールと最低44pxのタッチ領域を維持し、無理なボタン圧縮をしない。
- ページ内容や調査写真を隠す大きな追加パネル・常時表示の装飾・独立ボタンは追加していない。

## 5. 更新ファイル
- `ui-refinement.css`：新規。配色・操作状態の表示だけを指定。
- `index.html`：上部・右下Ver.1.4.51-dev、新CSSの読み込みを旧CSSの後に追加。
- `workspace.html`：ヘッダーVer.1.4.51-dev。
- `sw.js`：キャッシュ名を`field-survey-memopad-v1.4.51-ui-refinement-dev`へ、`ui-refinement.css`をプリキャッシュへ追加。
