## 追加要望と対応
- ユーザーがVer.1.4.37の設定パネル正常表示を実機報告。
- パレットのコンパクト化と指ドラッグ移動：本ブランチの既存変更を確認。
- 「線・背景・透明度」は別ダイアログを開く方式ではなく、色の近くに直接項目を表示：追加実装。
- `stamps-lines.js` の `#inlineLineProperties` を作成し、既存の色選択の直下に配置。線色、線種、全体の不透明度、背景色、背景の不透明度、背景なしを表示。
- 線・図形を選択中のとき、入力確定で選択オブジェクトの属性を直接変更。従来の `snapshot()` と `draw()` を使用し、元に戻す履歴を維持。背景の設定は四角/円にのみ適用。
- 選択対象がないときは表示したまま入力を無効化。既存のダイアログ機能のコードは残し、別呼出ボタンは表示しない。
- `tool-dock.js` は元のカラー選択と共に `#inlineLineProperties` を独立パネルへ移動。CSSは3列の省スペース表示。
- `index.html` の `stamps-lines.js` 読込キャッシュ指定を1.4.38へ変更。`app.js`、保存形式、PDF読込処理は未変更。
- GitHubから再取得し、上部/右下とも `Ver.1.4.38-dev`、CSS/JS/SWのバージョン、対象JSの構文を機械的に照合済み。
