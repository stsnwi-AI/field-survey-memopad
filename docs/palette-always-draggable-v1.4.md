# 現場調査メモパッド Ver.1.4 — パレット再移動・共有表示改善
更新日: 2026-11-11
開発ブランチ: develop/palette-always-draggable-20261111
基準ブランチ: develop/touch-pan-fixed-pages-20261111
公開版: この作業では変更なし
状態: 開発中、実機未検証

## 原因
既存 tool-dock.js の「上部へ戻す」は、フローティングモードを解除して移動ハンドルを非表示にする処理だったため、上部へ戻すと再度ドラッグ移動が直感的にできなかった。

## 対策
- 編集パレットを常にフローティングとして扱い、上部に配置ボタンは「上部の位置に戻す」だけに変更。
- 「⠿ 移動」の持ち手を上部に戻しても常時表示し、マウス・タッチのドラッグ動作を維持。
- 既存の「パレットを隠す・表示」は維持。再表示後も移動可能。
- 「表示・共有」メニューのラベルを「その他」に変更。共有用PDF生成・OS共有・共有用保存ボタンを「PDFを共有する（必要な場合のみ）」の折りたたみに収納。
- 通常の「編集済みPDFを保存」と「共有用PDFを作る」の役割を説明。共有は外部送信する場合の任意機能。
- 番号配置、写真、コメント、削除、固定ページ切り替え、指での図面移動、PDF一体保存を維持。
- オフラインキャッシュ名を更新。

## 静的検証
JavaScript構文・持ち手常時表示・移動処理・共有元ボタン残存・PDF保存処理・番号削除処理など12項目合格。

## 未検証
- PC、Android、タブレット、iOSのドラッグ操作と画面重なり。
- パレットを上部へ配置した後に再度ドラッグできるか、実機で確認。
- 必要時の共有生成・OS共有・保存、PDF一体保存・再読込。
- 新旧PWAキャッシュ遷移。
- ライブラリ／プロジェクト「ファイル（ソース）」への保存は未実施。

## 引継ぎ
- 試験用PDFを開き、パレットを移動→上部に配置→再移動→各編集操作→保存・再開を確認。
- 公開版/mainをユーザーの了承なく変更しない。
- 旧版の削除・上書きを行わず、既存機能・データを維持。
- 機密データの外部送信、ファイル変更などの共通セキュリティルールを尊重する。
