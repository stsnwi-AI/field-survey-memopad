## 指摘と調査結果
1. 「選択中の調査番号の記録を開く」は図面から番号を操作できるため不要。HTMLボタンと関連ハンドラを撤去。
2. Excelダウンロードボタンの押下結果が分からない。画面のエラー・状態欄が折りたたみ領域内部にあり、閉じた状態では不可視。常時表示できる出力ボタン直下へ移動し、押下受付、処理中、完了、失敗を表示。
3. 写真ZIPを押しても反応なし。survey-xlsx.js内に余計な閉じ括弧があり構文エラーだった。括弧を修正、出力ハンドラから写真をZIP保存できるよう復旧。
4. ユーザー画面にはPDFページ数「— / —」が表示され、編集済みPDF未読込の状態だった。ファイルなしの場合は明示的な案内を表示。
