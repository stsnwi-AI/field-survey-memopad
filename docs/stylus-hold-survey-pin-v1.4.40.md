# 現場調査メモパッド Ver.1.4.40-dev 開発記録
更新日：2026年11月16日

## 基準・GitHub
- 基準：`develop/dblclick-compact-mark-opacity-v1.4.39-20261116`
- 開発版：`develop/stylus-hold-survey-pin-v1.4.40-20261116`
- GitHub Pages公開元：変更していない（実機テスト時はユーザーが切り替える）。

## 不具合報告・原因
タブレットで調査番号の写真・コメント画面は指のダブルタッチで開くが、ペンでタッチしても開かない。
`survey.js` に指（pointerType='touch'）の2回タップとマウスのダブルクリックは実装済みだが、ペン（pointerType='pen'）専用の長押し処理が存在しなかった。
`app.js` の通常ペン入力へ流れると、長押しや指移動でピンが動く懸念がある。

## 修正
- `survey.js`：既存の調査番号（surveyId）のペン接触のみを対象に、650ミリ秒以上の長押しで`openRecord`を呼ぶ。
- 接触位置から12px以上移動したときは長押しをキャンセル。ペン接触時は図面エディタへ該当pointerイベントを流さず、誤移動や重複配置を抑制。短いペンタップは調査番号を選択する。
- 通常の指2回タップ、マウスのダブルクリック、ペンによる図面線描画、写真・メモの保存処理、PDF保存形式は変更なし。
- `index.html`：上部・右下ともVer.1.4.40-devに統一し、`survey.js`読み込みキャッシュ識別子を更新。
- `sw.js`：キャッシュ名を1.4.40へ変更。
- 既存の指操作、Ver.1.4.39の色・文字・線設定、Ver.1.4.35の指示スタンプ再読込修正を保持。

## 検証
- GitHub反映後のソース再取得、バージョン2箇所の一致、JS構文（survey.js/mobile.js/tool-dock.js）を確認済み。
- **未実機検証：** タブレットのペン長押し→写真・コメント画面表示、短押しでの選択、長押し中に番号が移動しないこと、指ダブルタッチ維持、ペン自動判定、PDF別名保存→再読込。
- 認識が`pointerType='touch'`になる静電式ペンは指と区別できないため、この長押しは適用されない可能性がある。その場合は端末・ブラウザの入力種別調査が必要。
- 旧版・main・元PDFは削除・上書きしていない。
