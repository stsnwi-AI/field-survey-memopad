# 現場調査メモパッド — 図面優先・クイック操作改善記録
更新日：2026-11-11
対象開発版：Ver.1.4
開発ブランチ：develop/quick-pin-delete-text-layout-20261111
基準ブランチ：develop/compact-tablet-header-v1.4-20261111

## ユーザー要望と今回の変更
1. 題名の下の補足行を非表示にする → CSSで非表示（元の文言は残す）
2. 「追加する文字」の行を常時表示しない → 文字追加ツールを押した時だけ表示。既存オブジェクトの文字編集欄はその文字を選択した場合に表示
3. 現場書き込みパレットに「調査番号 ON/OFF」ボタンを追加 → 元の調査番号配置ボタンを呼び出し、採番・記録・写真を扱う既存処理を維持。ほかの編集ツールへの切替で配置モードOFF
4. パレット内に「選択を削除」を追加 → 既存の削除ボタンに接続。スマホ・タブレットでは既存の削除確認ダイアログを維持
5. 移動パレット、図面ワイド表示、コンパクトヘッダー、PDF一体保存・復元を維持

## 実装ファイル
- app.js：文字追加時のみ新規テキスト入力欄を表示。既存文字の編集欄は選択時に表示。
- index.html：新ボタン2点、入力欄の初期hidden、読み込みスクリプトとキャッシュ識別子を更新。
- survey-quick-actions.js：既存調査番号・削除機能への安全な橋渡し。変更前の処理は削除せず。
- survey-layout.css：題名下補足の非表示、入力欄の非表示、操作ボタンの状態表示。
- sw.js：新規スクリプトをオフラインアセットに追加、キャッシュを改版。
