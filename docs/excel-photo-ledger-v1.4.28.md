# Ver.1.4.28-dev Excel 現場調査写真台帳
更新日: 2026-11-16

基準: develop/floating-text-composer-v1.4.27-20261113 (実機未検証)。Ver.1.4.25の主要操作・PDF保存復元は実機確認済み。
主な変更:
- survey-xlsx.js: JavaScriptのみで.xlsxを生成し、写真を埋め込み、調査メモと施工指示を編集可能なセルへ書き出す。
- survey.js: 現在のPDFの調査番号をページ・番号順に収集してExcelへ出力するボタン処理を追加。
- index.html: Excel写真台帳出力ボタン、スクリプト読み込み、版表示。
- sw.js: キャッシュ更新。
- A4横向き、調査番号・ページ・写真・メモ・施工指示の5列。写真複数は行追加。写真なしも出力。
- 元の編集済みPDFおよび記録情報は上書きしない。

検証: GitHubソースに必要なコード、画面ボタン、依存関係、既存のmobile.jsおよび文字小窓ファイルがあることを確認。
未検証: 実機での.xlsx生成、Excelによる読み取り・写真表示・印刷・編集、スマホの写真データ形式、Ver.1.4.27文字小窓。
main/既存ブランチは変更しない。Pagesの公開ブランチはユーザー操作により切り替える。
次の作業: Pagesに試用版を表示し、写真のある編集済みPDFから出力、PCのExcelで確認する。不具合があれば別ブランチで修正する。
共通ルール: 既存機能とデータを維持。削除・上書き・外部共有は事前承認。成果物は確定後ライブラリとProjectファイルの双方へ保存する。
