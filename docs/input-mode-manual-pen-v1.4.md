## 今回承認された仕様
- タッチペンを準備できていない時期も指やマウスで操作できるよう、上部に「手動操作／ペン操作」ボタンを置く。
- 初期状態は「手動操作」。画面のツールを選択して指で書き込みでき、既存の「見る・動かす」を選べば指で移動できる。
- 「ペン操作」時は指1本が図面移動、指2本が拡大縮小、対応ペンが書き込み。番号配置は既存の番号ボタンで明示してから行う。
- 対応ペンがWebブラウザーのPointerEventで pointerType='pen' として初めて検出されたら、自動でペン操作へ切り替える。
- ブラウザーからBluetooth等のペン接続状態を一般に直接判定することはできない。従って「ペンがつながった瞬間」ではなく、**ペンが最初に画面に触れたとき**に認識する。一般の静電式ペンはtouch判定のため自動切替されず、手動操作で使う。
- モードを切り替えただけでは書き込みや調査番号を追加しない。
