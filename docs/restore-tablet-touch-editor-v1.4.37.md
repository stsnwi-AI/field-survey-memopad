# Ver.1.4.37-dev タブレット編集・ペン/指操作の修正記録
更新日: 2026-11-16
基準: develop/compact-instruction-popup-v1.4.36-20261116

## 利用者からの不具合報告
- タブレットで「色・文字・線の設定」が小さく、内部スクロールが多い。押したとき独立した大きい設定パネルにしたい。
- ペンと指操作の反応が低下。ペン自動切替が見えなくなった。
- オブジェクトに触れたのに図面がスクロールして操作できない。

## 実装
- tool-dock.js と survey-layout.css: 元の色/フォント/サイズ/線幅/編集UIを再作成せず保持。独立した大きなパネルを画面内に開閉し、小型ドック内スクロールから分離。編集ボタンはドックに残し、外側タップ/Escで閉じられる。
- mobile.js: 選択済みオブジェクトやそのリサイズハンドルを指が触れたら、ペン優先モードでも図面パンよりオブジェクト編集を優先。未選択図面は従来どおり指でパン。1タップ選択→次ドラッグ編集を維持。
- input-method.js: Pointer Eventsでpenを検出する自動切替を pointerdown に加えて pointerover にも適用し、自動切替したときのラベルを「ペン自動」にする。静電式ペンがtouchとして認識された場合の自動判別は不可能なため手動切替を維持。
- index.html: 上部/右下ともVer.1.4.37-dev、CSS/JSの読み込みクエリ更新。
- sw.js: PWAキャッシュ名を1.4.37へ更新。
- app.js/survey.js/保存形式: 変更なし。1.4.35で実機確認したPDF指示ピン再読込修正を保持。
- 旧スタンプ/補助共有の非表示も継承。

## 検証

- **未検証**: 実機のタブレットで設定パネル全体が見えるか、ペン自動切替が認識されるか、既存オブジェクトの選択/移動/リサイズ、PDF別名保存/再読込、PC/スマホ。
