## ユーザーの不具合報告
丸頭の調査番号を付与してPDFを保存した後、再立ち上げでページを開けない。

## 確認できた原因
app.js 内の `validClipboardObject()` が `stamp` の `shape` を `rect` と `circle` のみに限定している一方、survey.js の新規調査番号は `shape:'survey-pin'`。PDF読込時に `restoreProject()` がすべての編集オブジェクトを `validClipboardObject()` で検証するため、丸頭ピンを含む再編集情報が拒否される。

## 対策
- 編集データ検証で `survey-pin` を許可。ただし既存の形状に加えて、調査記録ID `surveyId` と正の整数 `surveyNumber` を持つ番号ピンだけを許可し、異常なデータの検証は維持。
- 旧 `circle` / `rect` スタンプは引き続き許可。
- 保存・復元の既存データ構造、写真・メモと `surveyId` の紐付け、元PDFは変更せず維持。
- 常時表示のビルド番号を `Ver.1.4.16-dev / 2026-11-12` に更新し、app.js のキャッシュクエリと PWA キャッシュ名を変更。

## 既存機能の維持
丸頭のシンプルピン型、欠番の最小番号再利用、全ページ/ページ単位採番、写真・コメント・施工指示、上部ページ送り、指移動と端スワイプ、指/ペン切替、横一列編集バー/自由移動、別PDFのタブ、PDF一体保存・復元などの機能を削除していない。
