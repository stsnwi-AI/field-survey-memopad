# 現場ID別保存の開発メモ（2026-11-10）
対象: `develop/isolated-survey-records-20261110`。公開版 `main` は未変更。

## 仕様
- 現場調査パネルに現場IDの入力と「この現場で使用」を追加。
- 写真・コメント記録のIndexedDBキーを `site:<現場ID>:document:<PDF.js fingerprint>` に変更。現場名やPDF名のみでは識別しない。
- 現場ID未設定、PDF未読込、保存先判定失敗のときは新規調査番号の作成と保存を停止。元PDF編集機能はそのまま。
- 現場IDの最後の指定値は同じブラウザーのlocalStorageに保持。
- 既存 `document:<fingerprint>` と `latest` は消去しない。図面内の `surveyId` に一致するデータがあった場合だけ、確認後に新キーへコピー。
- バックアップには現場ID・保存キーを記録。異なる現場ID/ファイルへの復元を抑止。
- 保存する写真・コメントは端末内IndexedDBであり、端末間同期は行わない。

## 検証結果
- JavaScript構文検査成功。
- 識別キーの簡易単体試験: 現場違い・PDF違いで分離、同じ現場・同じPDFで一致、未指定では無効、8ケース合格。
- 実ブラウザーでのIndexedDB保存/復元、PDF切替、旧データ移行、スマホタッチ、PDF編集機能の回帰試験は未実施。
- GitHub全履歴の機密情報検査は未完了。

## 公開・利用上の注意
- PDF.js fingerprintはPDF内容の識別に使うため、同じ元PDFを同じ現場IDで再利用すると同一保存先になる。必ず現場IDを変える。
- 保存データを消した場合に備え、番号付きPDFと写真・メモJSONをセットでバックアップ。
- バックアップファイルは平文JSON。写真と現場情報の取り扱いに注意。
- 実機試験で保存成功と復元成功を確認するまで、確定版としない。
