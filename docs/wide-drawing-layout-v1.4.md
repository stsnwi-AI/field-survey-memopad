## 変更内容
- 設定・調査記録を常時表示する左ペインを撤去するのではなく、開閉できる独立したドロワーにした。
- 初期表示では設定パネルを閉じ、PDFワークスペースが幅を占有する。
- 左下の「設定・記録を開く」から既存の全コントロールを表示できる。
- パネル外クリック、閉じるボタン、Escで閉じる。番号配置モードを押すと図面が見えるよう自動で閉じる。
- 750px以下は上部編集ツールも初期非表示とし、既存の「編集ツールを表示」から開ける。
- PDF保存、写真、メモ、番号編集、旧バックアップ機能のJSハンドラーは維持。app.js / survey.js を変更せず。
- オフラインキャッシュに survey-layout.css / survey-layout.js を追加。新しいキャッシュ識別子を使用。

## 検証すべき事項
1. テスト用PDF読込後、設定パネルが閉じ、図面が横幅いっぱいに表示されること
2. 設定・記録を開閉してもPDF・書き込みが消えないこと
3. 番号配置を選ぶとパネルが閉じ、番号を配置できること
4. 写真・コメント・施工指示を編集してPDFを保存・復元できること
5. スマホ（縦横）・タブレット・PCでスクロール、ズーム、タッチ編集が保たれること
6. 古いオフラインキャッシュからの更新と、旧バージョンへの復帰が可能なこと
