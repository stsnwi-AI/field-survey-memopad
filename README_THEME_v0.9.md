# 現場調査メモパッド Ver.0.9 デザイン試作

- Ver.0.8試作版から派生した、デザイン変更中心の独立した試作版です。
- 上部ヘッダー・編集バー・左調査操作・調査ダイアログ・未読込画面を濃紺／スレートグレー／安全オレンジ基調に変更。
- `field-theme.css` にデザイン差分を独立して収録。元の `style.css`、`app.js`、`survey.js`、`tool-dock.js` 等の実装本体は変更していません。
- 未読込時の挿絵は、配線ルート・番号印の図面を模した内蔵SVGに置換。既存PDF表示は変更なし。
- ホーム画面テーマ色、PWA資産キャッシュをVer.0.9に更新。
- 番号配置、連続番号、ダブルクリック、写真・コメント、既存PDF編集操作は元ソースの機能を維持。
- 未検証：PC／スマホ実機での表示、PDFの読み込み・保存、既存機能回帰試験。

## 試す方法
ZIPを展開し、HTTPSの検証環境またはローカルHTTPサーバー経由で `index.html` を開き、PDF編集・採番・メモ・パレット移動を確認してください。ローカルファイルから直接開く場合、ブラウザーの制限で一部機能が使えない場合があります。
